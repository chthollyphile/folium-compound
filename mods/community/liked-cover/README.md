# 「我喜欢」封面 · Folia 模组

把资料库里「我喜欢」那一项的封面换成你自己的图。QQ 音乐不给改这个歌单的封面，所以它一直是那颗大爱心；这个模组只做这一件事，其它封面照旧由平台和 Folia 自己取。

## 安装

1. 打开 Folia 桌面版，进「设置 → 模组」，把最上面的**模组系统**开关打开（默认是关的，关着的时候不加载任何模组）。
2. 把 `liked-cover-1.0.0.zip` 整个拖进模组面板。
3. 列表里出现「「我喜欢」封面」后，点它右边的开关，在弹出窗口里确认（会告诉你它要读写的权限只有它自己的数据文件）。
4. 展开这一行，就是设置面板。

## 用

1. 点「选择图片…」，或者直接把图拖进虚线框。图片会在本地缩到 1024px、转成 WebP 存进模组自己的数据文件，不会上传。
2. 回到资料库看一眼：列表里「我喜欢」那格的封面就换了。此刻开着的面板/页面会立刻跟着变，不用重启。
3. 「铺满 / 完整显示」决定图片怎么放进那个方框：铺满会裁掉多余的部分（大多数封面图用这个），完整显示会留边。
4. 「恢复默认」删掉记录，回到平台原来那张图。

## 换不上去怎么办

模组认的是那一行的名字：Folia 把封面画成 `<img alt="这一项的名字">`，模组就按这个名字找。所以：

- 名字不是「我喜欢」（比如你自己改过，或者用的是别的音源）→ 在设置里把「列表里显示的名字」改成列表上实际显示的那几个字。
- 列表是海报墙（Bravais 资料库）而不是这个歌单列表 → 默认也会一起换（设置里的最后一项可以关掉）。
- 都不行 → 说明这个版本的 Folia 改了封面那块的写法，告诉我，我改选择器。

## 实现

- `mod.json`：`client.mjs` 一个入口，权限只有 `filesystem.data`（存你自己选的那张图），不联网、不读别的文件、没有 main 入口。
- 样式走 `folium.registries.styles`，注入的是三条规则：把 `img[alt="名字"]` 透明掉，用 `*:has(> img[alt="名字"])` 在它原来那个方框上画新图，再给 Bravais 海报墙那张卡补一条。
- 图片存成 data URL（`folia.storage`），运行时转成 `blob:` URL 交给 CSS —— 因为样式表有 64KB 上限，直接塞 base64 会被截断。
- 停用模组时样式、blob URL 一起撤掉，不留痕迹。

## 不做的

- 不改服务器上的数据，不动 QQ 音乐里的歌单，别的设备看到的还是原图。
- 不碰播放页、歌词页的封面。
