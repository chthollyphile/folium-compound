# 甜甜歌词 · sweet-lyrics

Folia（Folium 1）的甜歌 / 情歌专用歌词动画模组。纯渲染端实现，不联网、不读写文件、不申请任何权限。

## 效果

- **整句歌词**：奶白渐变的呆萌手写体，细描边、低发光，字距和大小随句长自适应。
- **11 种入场动画**：渐显、溶解、打字机、飞入、擦开、缩放、撞击、旋入、弹跳、光晕、波浪，按「文字 + 起始时间」固定抽取，同一句不会每帧乱变。
- **跟唱星星**：正在唱的字放大到 1.3 倍并轻微跳动；上方一颗五角星整句常驻、平滑跟随当前唱到的字，同时上下跳动；周围持续冒出大小、角度、速度都随机的小五角星，像叶子一样飘，跟不上的自然淡出，整句唱完才一起收起。
- **颜色状态**：未播放的字为灰色，播放后恢复奶白粉；星星从奶白粉渐变到暖金色。
- **大爱心**：从画面中心冒出，向随机方向扩散、由小变大，保持约 0.9 秒一次的心跳式收缩膨胀，到最大后像水泡一样炸开消失；另有一组低饱和淡色爱心做层次。
- **舞台灯光**：玫瑰 → 紫罗兰 → 冰蓝 → 青绿 → 琥珀 五组灯色每 5 秒循环，末尾交叉过渡；背景随灯色渐变，未照到的区域压暗；聚光灯跟随音频低频重音闪烁，并持续左右摇摆。
- **氛围装饰**：五瓣花、小爱心、四角星、圆片、气泡漂浮，涂鸦爱心随歌词逐字展开并在句末淡出。

## 安装

1. 在 Folia 的「设置 → 模组」里打开社区模组，选择本目录（或打包成 zip 后拖进模组页）。
2. 模组未经 Folium 签名时会弹原生确认框，点「仍要启用」。
3. 播放页的歌词样式面板切换到「甜甜歌词」；如果开着「每首歌随机歌词动画」请先关掉。

## 可调设置

| 设置 | 范围 | 默认 |
| --- | --- | --- |
| 爱心灯牌数量 | 6 ~ 12 | 8 |
| 星尘密度 | 0.2 ~ 2.5 | 1 |
| 舞台光束 | 开 / 关 | 开 |
| 显示下一句 | 开 / 关 | 开 |
| 字号 | 0.7 ~ 1.6 | 1 |
| 跳动幅度 | 0 ~ 1 | 0.7 |
| 字上小装饰 | 开 / 关 | 开 |

## 文件

- `mod.json` — 模组清单
- `client.mjs` — 渲染实现（纯 Canvas 2D）
- `font.mjs` — 内嵌字体（Dymon ShouXieTi 子集，WOFF2 base64）
- `preview.jpg` — 介绍图
