# OpenCC 繁體字幕

離線簡轉繁、自動尋找中文字幕與字幕載入失敗備援。模組 ID：`opencc-traditional-lyrics`。

## 安裝與設定

建議從 [Folium 模組市場](https://folium-compound.cielaniska.top/#mod-opencc-traditional-lyrics) 安裝經簽章的版本。GitHub 的專用 `opencc-traditional-lyrics-<版本>.zip` 可拖入 Folia「設定 → 模組」手動安裝；本儲存庫自行打包的 ZIP 未包含官方簽章。

啟用後預設開啟簡轉繁、自動尋找中文字幕、載入失敗後嘗試其他來源。搜尋使用 Folia 已設定的來源，需網路並沿用 Folia 的登入狀態；沒有 API 金鑰、額外伺服器或新增權限。插件不讀取帳號憑證，不下載執行遠端程式碼。純簡轉繁仍可離線使用，關閉兩個字幕搜尋選項即可。

## 字幕選擇

支援雙語歌名副標題與假名／羅馬字藝名，保留分部及版本資訊。先核對歌曲，再比較中文覆蓋率，排除明顯亂碼、佔位文字與異常時間軸；間奏不列入需要翻譯的行數。

原字幕可用時只補中文，保留正常逐字時間、原文分行、注音與和聲。兩邊最多核對 3 個相鄰分行；一個完整譯句可跨多個原文片段顯示。固定時間差須有多段原詞證據。原字幕為空時仍要求精確歌名、歌手與有效播放時間。

帶 Acoustic 等版本標記的雙語歌名可拆解搜尋，但每個別名都保留版本；Acoustic ver.／Version 等標記會正規化；雙語兩側重複的同一標記只保留一次。可逐字核對的假名姓名與兩個拉丁姓名詞允許前後換序，不猜漢字讀音或對任意拉丁藝名換序。整首原詞完全相同且順序一致、有至少 24 字與 3 個不同片段時，可只借其他錄音版本的中文，保留目前播放版本的原詞與動畫。

日本新字體（怪獸／怪獣）與翻唱附加資訊也會納入比對。歌手別名不確定時，須先以足夠原詞與時間軸證明，不能猜測並直接替換空字幕。

逐字資料缺失、全零或無效時，以有效行時間恢復基本文字與動畫；行尾時間缺失時，只從下一句已知時間或歌曲長度補回。正常逐字資料保持原樣，不改寫原檔。覆蓋安裝後請重新啟動 Folia。

音樂仍可由 YouTube Music 播放，字幕由網易雲等來源提供；模組不切換音樂。原有來源標籤未必反映模組改寫，請用命令查看實際字幕來源。若中文覆蓋率大於 0 而畫面沒有中文，請確認歌詞樣式的字幕設定包含翻譯。

每次最多讀 6 個來源，標準模式每個來源最多 2 個候選，深入模式最多 4 個。每個來源最多試 3 種歌名查詢，不無限翻頁。每個請求等 7 秒，整輪最多 40 秒；失敗就嘗試其他候選，全部失敗便停止。插件每分鐘最多 60 次讀取。結果只在記憶體暫存，最多 8 首、10 分鐘內避免重複搜尋；切歌會捨棄舊請求，切換帳號會清除暫存。

命令面板有「重新尋找中文字幕」、「還原這首歌的原字幕」及「查看字幕來源與中文覆蓋率」。狀態會列出逾時、需要登入、來源限制、請求上限、無匹配或無字幕等原因。還原只撤銷自動選字幕，簡轉繁仍依設定生效；該首自動搜尋暫停到重新尋找或暫存清除。停用整個模組會還原宿主字幕。

品質檢查不等於翻譯語意審核，無法保證找出全網最多或最準確的翻譯。無法核對的分行、版本或不穩定的時間差不會強行套用，也不會自行翻譯外文。

## 完整診斷報告

模組設定有「完整診斷報告」區，可捲動、選取文字、複製或下載 JSON。命令面板也有對應的查看、複製、下載命令。

更新後重新執行一次「重新尋找中文字幕」，等搜尋結束再下載；搜尋中的報告會標明尚未完成。逐筆紀錄包括來源、查詢、候選歌名與歌手、耗時、比對證據、中文行數、時間軸錨點及拒絕原因。請求上限區分插件額度與來源回覆，介面沒有提供的 HTTP 狀態或底層堆疊無法還原。

只在記憶體保留目前啟用期間的紀錄，沒有帳號、憑證、原始回應或整份歌詞；每輪最多 600 個事件，超出明示省略數。再次搜尋重建報告，切換帳號或停用清除。查看／匯出不啟動搜尋。1.1.6 已針對 0.7.25 實播報告修正名稱漏配；報告中的真實平台歌詞內容未隨附件提供，Windows 實播仍待確認。

## 簡轉繁

使用隨附 OpenCC 字典，可選臺灣字形或標準繁體，原詞與和聲、中文譯文可分別控制。只改顯示資料，不覆寫原始檔案。

日文歌若只需要中文字幕，關閉「轉換原文歌詞與和聲」。含假名或韓文的文字預設保留；純漢字日文無法可靠辨識。地區詞彙不做會改變字數的替換。

## 相容性、來源與授權

支援 Folia `>=0.7.22 <0.8.0`。自動搜尋需要 Folium 1.7 的公開 Omni 介面。沒有此介面時仍可簡轉繁。

插件程式採 MIT；內附 opencc-js 1.4.2 引擎採 MIT，OpenCC／opencc-data 字典採 Apache-2.0，完整條文見 `LICENSE` 與 `vendor/`。感謝 Folia、OpenCC、opencc-js、opencc-data 的作者與貢獻者。

原始碼、詳細限制與測試紀錄：[folia-traditional-chinese](https://github.com/Fringetw/folia-traditional-chinese)。

`vendor/opencc-jp-characters-1.4.2.mjs` 為 opencc-js 1.4.2 的固定日本新字體字元資料，採 Apache-2.0，僅供比對／搜尋，不以它改寫畫面日文。原有簡轉繁引擎與字典不變。模組設定標題與診斷訊息均顯示 v1.1.6，可用來確認實際載入的版本。

Folia 介面若只回傳 rate-limited，無法再確定是宿主配額還是平台限制；報告會標示不確定，不能據此認定某平台限流。
