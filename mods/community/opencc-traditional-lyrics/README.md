# OpenCC 繁體字幕 1.0.0

將 Folia 的簡體歌詞與中文譯文轉成繁體，預設採用臺灣字形。完整字典已包含在插件內，安裝後不需要網路、API 金鑰、Python 或另外安裝 OpenCC。

## 安裝

適用 **Folia 桌面版 0.7.22**；清單允許 `>=0.7.22 <0.8.0`，其他版本未實測。網頁版沒有這個桌面模組安裝流程。

1. 下載 `opencc-traditional-lyrics-1.0.0.zip`，不必解壓縮。
2. 開啟 Folia，進入「設定 → 模組」，開啟「模組系統」。
3. 將 ZIP 拖曳到模組面板。
4. 啟用「OpenCC 繁體字幕」，完成 Folia 的模組啟用確認。
5. 播放有歌詞的歌曲；已在播放的歌曲也會立即重新套用。

這是第三方模組，未經 Folium 官方簽署，因此會顯示「未驗證／未验证」，這是正常的來源標示。請安裝這份安裝 ZIP；`-source.zip` 是開發原始碼包。

若拖曳無效，可解壓縮後，在模組面板按「開啟模組目錄」，將 `opencc-traditional-lyrics` 資料夾放入，再回到面板重新載入並啟用。資料夾內應直接看到 `mod.json` 和 `client.mjs`。

## 功能與設定

- 原文歌詞、和聲與中文譯文可以分別控制。
- 可選「臺灣繁體」或「OpenCC 標準繁體」。
- 先整句轉換，再對回原本的逐字、音節與分詞邊界，保留時間戳、聲部和注音資料。
- 設定變動會立即更新目前歌曲；停用會從未轉換的來源還原。
- 命令面板提供「切換繁體字幕」。
- 僅改變傳給播放器的顯示資料，不覆寫原始歌詞檔。

若主要聽日文歌，且只希望轉換底下的中文翻譯，**關閉「轉換原文歌詞與和聲」，保留「轉換中文譯文」**。

預設保留含假名或韓文的原詞與譯文，並略過標明非中文的其他語言譯文和羅馬拼音。不過，純漢字日文無法靠歌詞文字可靠辨識；混合中文與假名的同一行也會整行保留。可以透過上述設定選擇只轉譯文。

本插件做中文簡繁轉換，不會把日文、英文等其他語言翻譯成中文。不採用 `s2twp` 地區詞彙替換，避免「網際網路」這類字數改變造成逐字同步偏移；例如「软件」會轉成「軟件」，不會改寫成「軟體」。

## 相容性與檢查

已針對正式版 `v0.7.22` 和開發分支執行 41 項自動測試，並通過 Folia 的模組檢查工具與實際 ZIP 安裝程式。完整範圍、修正項目與尚未驗證的部分見 `VALIDATION.md`。

沒有在使用者的 Windows 電腦實際播放與操作 GUI；若遇到問題，可到「設定 → 模組」展開本模組，查看錯誤明細。與其他會改寫歌詞的模組同時啟用時，最終結果可能受處理順序影響。
