# OpenCC 繁體字幕

離線簡轉繁、自動尋找中文字幕與字幕載入失敗備援。模組 ID：`opencc-traditional-lyrics`。

## 安裝與設定

建議從 [Folium 模組市場](https://folium-compound.cielaniska.top/#mod-opencc-traditional-lyrics) 安裝經簽章的版本。GitHub 的專用 `opencc-traditional-lyrics-<版本>.zip` 可拖入 Folia「設定 → 模組」手動安裝；本儲存庫自行打包的 ZIP 未包含官方簽章。

啟用後預設開啟簡轉繁、自動尋找中文字幕、載入失敗後嘗試其他來源。搜尋使用 Folia 已設定的來源，需網路並沿用 Folia 的登入狀態；沒有 API 金鑰、額外伺服器或新增權限。插件不讀取帳號憑證，不下載執行遠端程式碼。純簡轉繁仍可離線使用，關閉兩個字幕搜尋選項即可。

## 字幕選擇

先比對歌曲名稱、歌手、版本與已知時長，保留括號內的分部與版本資訊；模糊歌名不會用於整份備援。再比較中文譯文覆蓋率，排除明顯亂碼、佔位文字與異常時間軸。原字幕可用時，只補上原文相同、時間接近的缺漏譯文，保留原本逐字時間軸、注音與和聲；原字幕不可用時才嘗試整份備援。已有完整且格式正常的中文字幕時會保留。

每次最多讀 6 個來源，標準模式每個來源最多 2 個候選，深入模式最多 4 個。每個請求等 7 秒，整輪最多 40 秒；失敗就嘗試其他候選，全部失敗便停止。插件每分鐘最多 60 次讀取。結果只在記憶體暫存，最多 8 首、10 分鐘內避免重複搜尋；切歌會捨棄舊請求，切換帳號會清除暫存。

命令面板有「重新尋找中文字幕」、「還原這首歌的原字幕」及「查看字幕來源與中文覆蓋率」。狀態會列出逾時、需要登入、來源限制、請求上限、無匹配或無字幕等原因。還原只撤銷自動選字幕，簡轉繁仍依設定生效；該首自動搜尋暫停到重新尋找或暫存清除。停用整個模組會還原宿主字幕。

品質檢查不等於翻譯語意審核，無法保證找出全網最多或最準確的翻譯。與原詞分行或時間差太大的翻譯不會強行拼接，也不會自行翻譯外文。

## 簡轉繁

使用隨附 OpenCC 字典，可選臺灣字形或標準繁體，原詞與和聲、中文譯文可分別控制。只改顯示資料，不覆寫原始檔案。

日文歌若只需要中文字幕，關閉「轉換原文歌詞與和聲」。含假名或韓文的文字預設保留；純漢字日文無法可靠辨識。地區詞彙不做會改變字數的替換。

## 相容性、來源與授權

支援 Folia `>=0.7.22 <0.8.0`。自動搜尋需要 Folium 1.7 的公開 Omni 介面。沒有此介面時仍可簡轉繁。
