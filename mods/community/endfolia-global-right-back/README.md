# ENDFOLIA全局右键返回

ENDFIELD 的全局右键返回用起来很顺手，所以把这个操作带到了 Folia。在主窗口按一下右键，就能退回上一层。有弹窗、命令台或播放控制面板时，先关闭当前界面。

适配 Folia v0.7.28 及更新版本。在 Folia 的「模组」面板导入 ZIP，然后启用「ENDFOLIA全局右键返回」。展开模组可看到「右键返回方式」。Shift＋右键启动原菜单。

- **靖歇**。使用 Folium 的 `folium.ui.back()`。海报展开或磁贴有焦点时先清掉状态，再次右键才回退上级。
- **翻覆**。正式版显示「未开放」。

模组使用 Folium 的返回和设置接口，无权限声明，无依赖。许可证为 MIT。
