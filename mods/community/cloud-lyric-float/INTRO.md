# 云☁️风悬浮歌词（cloud-lyric-float）

云☁️风悬浮歌词是一款面向 FOLIUM / Folia 的桌面歌词模组，由siyii11 与大肥鱼共同完成。

模组将歌词从播放器中独立出来，以透明、置顶、无边框的悬浮窗展示。当前歌词支持逐字点亮，未唱部分可以单独设置颜色、透明度和后续歌词大小；同时支持翻译、音译、单行/双行/多行排版，以及长句自动滚动。

## 主要功能

- 透明置顶歌词窗，支持拖动和鼠标穿透
- 当前句逐字高亮，未唱歌词独立配色与透明度
- 翻译、音译和多种歌词排版
- 独立可移动的外观设置窗
- 可选择的左键拖动、右键长按拖动
- 歌词范围提示、重置位置呼吸灯
- 锁定后在歌词上方中央显示解锁图标
- 一键回到 Folia 主窗口
- 字号、颜色、位置和拖动配置自动保存
