# 云风桌面歌词（cloud-lyric-float）

FOLIUM / Folia 的桌面悬浮窗歌词模组，由 siyii11 与大肥鱼共同完成。以云风桌面歌词为视觉方向：透明置顶、当前句逐字点亮、翻译、控制条与鼠标穿透。

## 制作

本项目由项目作者与大肥鱼共同完成。

## 功能

- **独立透明窗口**：无边框、跳过任务栏、始终置顶，不抢播放器焦点。
- **动态自适应尺寸**：渲染端实测当前歌词、译文和控制条宽度，回传主进程实时缩放窗口，避免固定大窗口造成的空气墙。
- **完全透明歌词区**：歌词容器不绘制底衬、环境光或红色投影，只保留文字本身的黑色可读性阴影。
- **逐字染色**：优先使用歌词的 word 级时间轴；没有逐字数据时按整句时间均匀拆分。
- **三种排版**：单行、双行、多行歌词板。
- **双语歌词**：显示翻译；可选显示音译。
- **长句滚动**：当前句超出窗口宽度时，按该句剩余时间自动横向滚动。
- **悬浮窗控制**：上一首、播放 / 暂停、下一首、字号、设置、锁定、隐藏。
- **可配置拖动**：默认在歌词文字上按住左键即可直接拖动；设置面板可切换为“右键长按”或“两者都开”。
- **未唱歌词独立设置**：可单独设置尚未唱到的颜色、透明度和后续歌词大小比例；当前句尚未点亮的字和下一句会同步使用。
- **歌词悬停范围提示**：只有鼠标位于歌词文字范围内时，才在文字下方显示淡淡的半透明灰色覆盖层；覆盖层紧贴实际歌词文字，不再覆盖整个透明窗口，也不再显示占空间的尺寸标签。
- **歌词中央解锁**：锁定后不显示右上角小锁。鼠标移到歌词文字上时，只在歌词上方中央显示一个解锁图标，并上移留出与歌词的间距；移开歌词后自动隐藏。主进程直接检测系统鼠标位置，确保锁定状态下可以点中解锁图标。
- **锁图标**：独立设置窗里的锁定操作也改成了锁图标。
- **独立外观设置窗**：设置界面从歌词窗口中彻底拆出，成为单独的无边框悬浮窗；按住设置窗标题栏可自由移动，并记住上次位置。
- **调节时可见歌词**：设置窗与歌词窗互不覆盖，调整字号、颜色、模式时可以实时看到歌词效果。
- **回到软件**：顶部控制栏新增“回到 Folia”按钮，可恢复并聚焦 Folia 主窗口。
- **前奏提示**：未开始演唱时“♪ 前奏”显示在歌词区域顶部，不再夹在上下两句歌词中间。
- **鼠标穿透**：锁定后点击和拖动落到桌面下面的软件；从 Folia 播放条入口或命令面板解锁。
- **配置记忆**：位置、字号、颜色、模式、锁定和快捷键状态自动保存。
- **无外部资源**：全部 HTML / CSS / JS 本地运行，不请求网络，不加载第三方网页。

## 安装

1. 在 Folia 打开 `设置 → 系统 → 模组`，启用模组系统。
2. 下载发布包 `cloud-lyric-float-1.8.3.zip`，不要解压。
3. 把 zip 拖进模组面板，启用 `云风桌面歌词`。
4. 播放一首歌，桌面底部会出现双行歌词。

这是自行构建的模组，没有 Folium 官方签名。启用时显示“未签名 / 签名不匹配”属于正常现象，请只安装来源可信的 zip。

## 操作

| 操作 | 方法 |
| --- | --- |
| 移动窗口 | 长按右键约 0.36 秒后拖动；窗口会被限制在当前屏幕工作区内 |
| 显示控制条 | 鼠标移到窗口上 |
| 查看可交互范围 | 鼠标放到歌词文字上，文字下方显示半透明灰色覆盖层和 `交互范围 · 宽 × 高` |
| 锁定 / 解锁 | 未锁定时点顶部控制栏的锁图标；锁定后把鼠标移到歌词文字上，点击歌词上方中央的解锁图标 |
| 调整字号 | 在独立设置窗点击 `A− / A+` 或拖动字号滑杆；范围 16–96，歌词文字会实际缩放 |
| 修改颜色 / 模式 | 点击控制条齿轮或短按右键窗口，打开独立外观设置窗；未唱歌词有独立颜色、透明度和大小设置 |
| 回到 Folia | 点击顶部控制栏的窗口图标 |
| 隐藏 | 控制条 `×`；Folia 播放条云朵按钮可重新显示 |
| 窗口找不到 / 位置异常 | 执行「重置窗口位置」会把歌词窗移到屏幕中央，并让歌词范围框呈现呼吸灯提示；鼠标移到歌词上即停止闪烁 |
| 关闭设置窗 | 单击右上角关闭按钮，或双击标题栏/非控件空白处 |
| 拖动异常排查 | 在独立设置窗点击“打开诊断日志”，或点击“清除诊断日志”清空日志 |
| 全局快捷键（可选） | `Ctrl+Shift+H` 显隐、`Ctrl+Shift+L` 锁定、`Ctrl+Shift+←/→` 切歌、`Ctrl+Shift+Space` 播放暂停 |

全局快捷键默认关闭，避免抢占其他软件按键。可在设置面板打开。

## 权限

- `playback.read`：读取当前歌曲、播放进度和歌词行。
- `playback.control`：控制条里的上一首、下一首、播放暂停。
- `filesystem.data`：保存窗口位置和外观配置到模组自己的数据目录。

## 兼容性

- Folia `>=0.7.20 <0.8.0`
- Windows / macOS / Linux 的 Electron 窗口能力可用；鼠标穿透在 Windows 上体验最好。

## 开发说明

- `main.cjs` 通过 `api.runtime.getPlaybackSnapshot()` 读取播放快照，约 80ms 推一次。
- 窗口渲染端用 `requestAnimationFrame` 在快照之间插值，避免歌词在高刷新率屏幕上卡顿。
- 所有歌词文本都通过 `textContent` 写入，不把远端数据拼进 HTML。
- 主进程只信任自己创建的歌词窗口发来的 IPC。

## 拖动日志

每次右键按下、进入待拖、开始拖动、位移、结束、布局测量和窗口 resize 都会写入：

```text
%APPDATA%\Folia\mods-data\cloud-lyric-float\files\cloud-lyric-float.log
```

日志包含时间、系统鼠标坐标、窗口 bounds、冻结尺寸、布局请求/应用、显示器 bounds / workArea / scaleFactor。文件超过 1 MB 时会在下次启动时自动清空。可在命令面板执行「云风桌面歌词：打开拖动诊断日志」直接打开。
