# 星潮·银河 Stardrift

作者：w0w1w2（AI 辅助开发）

Folia 全屏歌词动画模组（Folium visualizer）。纯渲染端，无 main、无权限。

## 效果

- 背景是一片随机更替的星海：四角星（圆润星芒）在随机位置、随机时刻冒出来，按各自大小与较慢节奏闪亮、变大变小，再淡出消失。
- 不时有流星从屏幕外滑入、斜向穿过画面再滑出：拖尾是一条由亮到透明渐隐的光带，头部是与背景一致的四角星，属于背景层，切行与换主题都不会消失。
- 每个正在读的字亮起一个柔和的透明光圈罩住它：圈与字的视觉大小严格同步，字出现圈一起慢慢变大罩住，正在读时保持，读完后圈快速缩小变淡消失。
- 歌词每个字在屏幕随机位置独立呈现：先是一颗小光点，按缩放时间放大成字（正在读的字为主题色，带辉光），唱完后停留显示，再变回强调色并缩小消失。
- 空格不渲染成字（不会出现"空字空圈"）；标点符号可以屏蔽（默认开）；英文字母与数字可以不亮光圈（默认开）。

## 稳定性修复（v1.34–v1.38）

- 屏蔽标点改为显式白名单，不再误吞间隔号「·」等符号型字符。
- 修复进度条拖动（seek）后背景消失、画面空白卡住的问题。
- 修复个别歌词行因数据时间戳错位（行尾字被标到行末）导致读词时该字不渲染的问题；修正规则只针对"行尾字 + 行尾大段空白"的强错位特征，不会误伤本来就慢速隔开的歌词。

## 安装

1. 在 Folia「设置 → 系统 → 模组」里开启模组系统。
2. 下载 zip，拖进模组面板。
3. 启用时核对确认窗口里的签名与权限（本模组无需权限）。

## 设置项

| 设置 | 说明 | 范围/默认 |
| --- | --- | --- |
| 变化速度 | 字出现/淡出的整体节奏 | 0.5–2，默认 1 |
| 辉光强度 | 字的辉光浓淡 | 0–2，默认 1 |
| 星星数量 | 背景星海密度 | 30–300，默认 150 |
| 字号 | 歌词字大小 | 0.6–1.6，默认 1 |
| 音乐呼吸 | 跟随音乐强度呼吸 | 开关，默认开 |
| 读字光罩 | 正在读的字的光圈总开关 | 开关，默认开 |
| 英文不亮圈 | 英文字母与数字不显示光圈（中文照常） | 开关，默认开 |
| 屏蔽标点 | 标点符号不显示、也不亮光圈 | 开关，默认开 |
| 星星大小 | 背景星星大小倍率 | 0.5–2，默认 1 |
| 光罩深浅 | 光圈浓淡（0=不显示） | 0–2，默认 1 |
| 光圈大小 | 光圈罩住字的范围 | 0.5–2，默认 1 |
| 字停留 | 唱完后的停留时长（秒） | 0–5，默认 0.5 |
| 字缩放时间 | 字放大时长（秒，不超过停留时间） | 0.2–5，默认 0.5 |
| 流星数量 | 同屏最多几颗流星（0=关闭） | 0–3，默认 1 |
| 流星大小 | 流星头部与拖尾大小倍率 | 0.5–2，默认 1 |

## 兼容性

- Folium 1.x（mod.json 声明 `folium: 1`，只使用基础 visualizer 契约）。
- Folia 0.7.21+（mod.json 声明 `folia: ">=0.7.21"`，使用 `ctx.lyricTime`）。
- Folia 0.7.x 实测通过（Folium 1.7）。
