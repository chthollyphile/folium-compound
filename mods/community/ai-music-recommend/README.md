# AI 推荐音乐（ai-music-recommend）

Folia / Folium 模组。记录你平时的听歌喜好，用 **OpenAI 兼容接口** 让 AI 根据你的口味推荐新歌，并自动在音源里搜索匹配成可播放的曲目。

**与官方「听歌档案」模组联动**：检测到 listening-archive 的按月播放日志（）时，自动把它的长期记录（逐秒收听数据）并入推荐档案；没有装它也照常工作，用本模组自己记录的数据。可在设置里关闭联动。

## 功能

- **听歌档案**：后台记录每次播放（听满 30 秒记一次）、快速切歌记为「跳过」，全部保存在本机。
- **AI 推荐**：首页新增「AI 推荐」标签页。点「生成推荐」，模组把你的常听歌手、常听歌曲、最近播放与跳过记录整理成档案交给 AI，要回一批推荐。
- **自动匹配**：每条推荐会用 Omni 在你的在线音源里搜索，按歌名+歌手相似度挑选最佳匹配；同名多版本（原唱/翻唱/女声版）时叠加「歌手熟悉度」加权——**优先匹配你更常听的版本**；匹配上的可以直接「播放」或「加入队列」。
- **自动入队**（可选设置）：匹配成功的歌自动接在当前队列后面；队列空着就直接开始播放。
- **不感兴趣**：进度条右侧的大拇指朝下按钮，点击即对当前歌记一次负反馈（歌手 + 这首歌），AI 之后的推荐会避开它们及其相似版本；电台运行中还会把队列里同歌手的待播推荐移除。推荐页可查看/清空排除清单；记录半年自动失效。
- **推荐电台（连播模式）**：进度条右侧的电台图标 / 推荐页的「点击 → 生成新推荐 → 开启电台连播」按钮 / 命令面板「推荐电台」三处入口。**每次开启都现场生成一批全新推荐**，接管队列立即连播（当前正在放的歌让位，原歌单自动快照收起）；之后每次换歌检查队列——当前歌之后不足 2 首时自动生成下一批并无缝追加，无限续播；队列里已有的歌不会重复补充，歌手对不上的版本不进电台。**关闭电台（或崩溃后下次启动）自动恢复原歌单**。

## 设置（模组面板 → AI 推荐音乐）

| 设置 | 说明 |
| --- | --- |
| 接口地址 | OpenAI 兼容接口，`https://host`、`https://host/v1` 或完整端点都可以，自动补 `/chat/completions` |
| 模型 | 例如 `gpt-4o-mini`、`deepseek-chat` |
| API 密钥 | 加密保存在本机（Folium secret 机制），不经过明文 |
| 温度 | 越高越敢推，默认 0.8 |
| 每次推荐数量 | 3–20 首 |
| 搜索到后自动加入队列 | 默认关 |
| 额外偏好 | 例如「多来点日语歌」，会一并交给 AI |
| 联动「听歌档案」 | 默认开：检测到官方听歌档案模组的记录就并入推荐档案 |
| 记录我的听歌历史 | 关掉后不再记录新播放（已有记录仍会读取） |

## 需要的宿主版本

- Folia ≥ 0.7.22（Folium 1.7），权限只声明 `filesystem.data` 与 `playback.control`。
- AI 请求由主进程经 Electron `net.fetch` 发出（跟随系统代理，不受渲染进程 CORS 限制）。

## 文件

```
mod.json     清单
main.cjs     主进程：OpenAI 兼容请求（重试梯子、密钥脱敏、90s 超时、停用时中止）+ 听歌档案日志读取（mtime 缓存）
archive.cjs  听歌档案 JSONL 的解析与聚合（宽容解析，坏行跳过，独立可测）
client.mjs   渲染进程：历史追踪、设置、首页标签页 UI、Omni 搜索匹配、播放控制、档案合并
preview.png  模组面板预览图
```

## 本地开发

把本目录放进 `%APPDATA%\Folia\mods\`（或源码运行的仓库 `mods/`），在模组面板重载即可。改完文件点「重载」无需重新确认。
