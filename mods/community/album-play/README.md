# 专辑随机与专辑循环（album-play）

给 Folia 的播放队列补上宿主没有的**专辑级**播放方式：

- **专辑随机**：整张专辑当作一个单位洗牌，一张专辑里的歌始终连在一起、顺序不变（宿主自带的随机是单曲级）；
- **专辑循环**：把队列换成当前这张专辑并设为列表循环，放完最后一首回到第一首；
- **上一张 / 下一张专辑**：按队列顺序跳到相邻专辑的第一首；
- **撤销上一次**：把队列和循环模式放回上一次专辑操作之前（在专辑循环里就是退出循环）。

这是一个 Folium 客户端模组，只用公开接口（`playback.getQueue`、`replaceQueue`、`setLoopMode`），不含主进程代码，也不碰宿主的音频链。

## 安装

需要 **Folia 桌面版 + Folium 1.7 或更高**（`replaceQueue` 从 1.7 开始提供）。

方式一：拖 zip

1. 打开 设置 → 模组，把总开关打开；
2. 把 `album-play-x.y.z.zip` 直接拖进模组面板；
3. 在列表里找到「专辑随机与专辑循环」，启用并确认权限（`playback.control`、`playback.queue`）。

方式二：放目录

把整个 `album-play` 文件夹放进用户模组目录（Windows 一般是 `%APPDATA%\folia\mods`，以设置页显示的路径为准），重启或刷新模组列表，再启用。

如果这是开发版 Folia，也可以把文件夹放进仓库的 `mods/` 下。目录里有 `mod.json` 和 `client.mjs` 就能用，没有构建步骤。

启用后如果改了 `client.mjs`，需要重新启用一次（授权绑定的是目录内容指纹）。

## 用法

三种入口，功能一样：

1. **命令面板**（Ctrl/Cmd + K）：
   - `专辑随机播放`
   - `循环这张专辑`
   - `下一张专辑` / `上一张专辑`
   - `撤销上一次专辑操作`（在专辑循环里就是退出循环）
2. **播放器面板**新增的「专辑」标签页：显示当前专辑、专辑循环状态，五个按钮直接点；循环中「撤销上一次」会变成「退出专辑循环」。
3. **设置 → 模组 → 本模组**：两个行为开关。

### 设置项

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| 保留当前专辑在最前 | 开 | 随机时把正在播放的专辑放最前，当前这首不中断；关掉则连它一起洗 |
| 随机后设为列表循环 | 开 | 专辑随机完把循环模式设为「列表循环」，一轮放完自动从头再来 |

## 行为细节与限制

- **分组键是「来源 + 专辑名」**，不区分大小写。合辑（一张专辑多个艺人）不会被拆散；没有专辑名的歌各自单独成组，不会凑成一张假专辑。
- **专辑内顺序只能沿用队列原顺序**。Folium 的 `FoliumSong` 只有 `album` 字符串，没有碟号、曲序号，所以模组无法把队列里乱序的同专辑歌曲重新排对。想要正确顺序，先按专辑顺序把队列排好再随机。
- **随机是整表替换队列**：个人 FM 会被结束（这是 `replaceQueue` 的既定语义），正在播放的歌不会被打断。
- **模组成功会弹一条 toast**：「已按专辑随机：N 张专辑 / M 首」/「循环专辑《X》：N 首」。`folium.ui.toast` 和宿主那条「某模组替换了队列 · 撤销」共用同一个提示通道（`useStatusMessageStore`），后写的覆盖前面的，所以宿主那条基本看不到——这是有意取舍，撤销由模组自己提供。
- **撤销就是唯一的还原入口**：没有单独的「恢复原队列」命令或按钮。在专辑循环里，「撤销上一次专辑操作」就是退出循环（队列回到进循环之前、循环模式也回去）；在普通队列里，它撤销上一次专辑随机。撤销只保留最近一层，模组重新加载后清空。
- **宿主自己的撤销还在**：命令面板的「撤销模组替换的队列」等价于宿主提示条上的按钮（回到上一次替换之前，在队列再被改动之前有效），两条路都行。
- **下一张 / 上一张专辑**按**当前队列顺序**找相邻专辑，跳到那张专辑的**第一首**，到末尾回到第一张、到开头回到最后一张。它只换播放位置，不改队列，所以不占撤销栈、也不会触发「某模组替换了队列」提示。
- **在专辑循环里按下一张 / 上一张**：先退出循环（队列回到进循环之前），再按原队列顺序跳过去。队列里只有一张专辑时会提示没有别的专辑可切。
- **专辑循环期间队列就是这张专辑**：此时在宿主队列面板里看到的也是这张专辑；退出（撤销命令 / 面板「退出专辑循环」）后恢复原队列。若你在循环期间自己把循环模式改掉，模组会恢复原队列，但保留你选的循环模式，且不占用撤销栈。
- **外部 Stage 播放、个人 FM 队列里不会生效**，会提示只能在普通播放队列使用。
- **队列上限 5000 首**（`replaceQueue` 与宿主 ref 池的上限），超过会提示不支持。
- **和宿主自带的随机互斥**：宿主的随机按钮仍是单曲级、按轮不重复；两个一起用没有意义。模组的入口是独立的命令/面板，不会改写宿主按钮的行为。
- 专辑循环的状态只存在内存里。模组被重新加载后，请用命令面板的「撤销模组替换的队列」恢复，或直接重新排队列。

## 开发

```powershell
node --check .\album-play\client.mjs
node .\test\mock.test.mjs
```

`test/mock.test.mjs` 用假的 `folium` 接口跑 25 个断言，覆盖：专辑分组、专辑内顺序、当前专辑置顶、洗牌、专辑循环进入/退出、撤销（含循环中途撤销）、用户改循环模式、外部改队列、`stale-version`/`rate-limited`/`transition` 重试、上一张/下一张（正常、回绕、循环中切换、跳转失败）、单专辑、个人 FM 拒绝、版本过低退出。

`preview.jpg` 是模组市场卡片图（1280×720），只给市场和设置页展示用，不影响运行。

宿主契约参考文件放在同级的 `.ref/`（`folium.d.ts`、`contract.ts`、`api.md`、`mods-readme.md`），来自 folia-major 仓库。
