# 落雪歌单转换（lxmc2folia）

把洛雪（LX Music）导出的 `.lxmc` 歌单转换成 Folia 的歌单文件（`.folia-playlist.json`），
再用 Folia 的「导入歌单」导入成一张 Folia 歌单。

纯本地工具：只读你选中的 `.lxmc` 文件，在内存里转换，**不联网、不下载音频、不上传任何东西**。

## 用法

1. 设置 → 模组 → 启用「落雪歌单转换」
2. 首页导航里出现「落雪歌单转换」页面（也可以在命令面板运行「打开落雪歌单转换」）
3. 把 `.lxmc` 拖进页面（或点击选择文件）
4. 按需填写歌单名、勾选「标记为我喜欢的音乐」「包含本地歌」，点「转换」
5. 点「保存到下载文件夹」——Folia 歌单文件会写到系统的「下载」目录
6. 打开 Folia 的本地音乐 / 歌单区域 → 操作菜单 →「导入歌单」→ 选择刚才保存的文件

## 转换规则

| LX 平台 | 转换后的 Folia 洛雪音源 id |
| --- | --- |
| 网易云 wy | `wy:<歌曲id>` |
| QQ 音乐 tx | `tx:<songmid>`（另带 songId / strMediaMid / albumMid / albumId） |
| 酷狗 kg | `kg:<32 位 hash>` |
| 酷我 kw | `kw:<rid>` |
| 咪咕 mg | 跳过（Folia 洛雪音源不支持咪咕） |
| 本地 local | 只写文件名 + 时长线索，导入时在曲库里按文件名认，认不到就跳过 |

其它处理：

- 去重（同一首歌只留一条）
- 封面只保留公开的 http(s) 地址，带 token / 参数像凭据的、内网地址的封面会被丢掉
- 歌名、歌手、歌单名里的控制字符会被清掉
- 同名的 Folia 歌单文件不会覆盖，自动加 `(2)`、`(3)` 后缀
- 歌按原歌单顺序排

## 已知限制

- 转换只负责把歌单变成 Folia 能读的文件；**能不能播放取决于你在 Folia 里启用的音源和导入的洛雪脚本**。脚本是第三方代码，Folia 不提供也不审核，来源与可用性由你自己负责。
- `.lxmc` 是洛雪自己的导出格式，洛雪更新格式时这个模组可能需要跟着更新。
- 转成 Folia 歌单后，歌曲引用的是洛雪音源；如果 Folia 里洛雪音源被停用，歌单还在，只是暂时播不了。

## 权限

`permissions: []` —— 不需要任何 Folia 权限。主进程入口只负责把转换结果写进系统下载文件夹，
客户端入口只读用户主动选择的那个文件。

## 开发

- `client.mjs`：页面 UI + 转换核心（`parseLxmcBytes` / `convert` 导出，方便单独测试）
- `main.cjs`：`api.rpc.handle('save-file')`，把 JSON 写进下载目录
- 无依赖，无构建步骤
