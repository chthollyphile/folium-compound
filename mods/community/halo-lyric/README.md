# Halo PixelBar 歌词（Folia 模组）

把 Folia 正在播放的歌词行，实时推到 **花再 Halo PixelBar** 音响的点阵屏上。

## 它做什么

- 每 60ms 读一次 Folia 的播放状态和歌词行
- 按当前唱到的字算窗口位置，长歌词在屏上匀速横向滑动
- 换行时播放进场动画（逐字打出 / 从右滑入 / 闪烁 / 双闪 / 擦除后重打）
- 暂停时行首带 `II`

## 前置条件（重要）

这个模组只负责“告诉屏幕显示什么”，真正往屏幕写数据的是配套的
**HaloBridge** 桥接程序（Windows，走 USB HID）。没装桥接程序的话，模组能启动但屏幕上不会出现歌词。

桥接程序：

- 需要 Windows
- 需要 Python 3.9+（装好后运行 `install_bridge.bat`，脚本会自建虚拟环境并装 `hidapi`）
- 启动后没有窗口，托盘里也看不到；桥接程序由 `watch_folia.py` 管理：Folia 打开时自动起，Folia 关闭时自动停

## 冲突提醒

**EDIFIER TempoHub 必须关闭。** 它和桥接程序会抢同一个 HID 通道，两边同时写会出现歌词乱跳。

## 设置项

Folia → 设置 → 模组 → Halo PixelBar 歌词：

| 设置 | 默认 | 说明 |
|---|---|---|
| 跟随播放进度 | 开 | 窗口跟着唱到的字走；关掉则匀速滚 |
| 延迟补偿（毫秒） | 0 | 歌词比声音晚就填负数（如 −300），早就填正数 |
| 换行动画 | 逐字打出 | 五种进场效果可选 |
| 滑动帧间隔 | 220ms | 关闭跟随后生效 |
| 每帧位移 | 1 字 | 关闭跟随后生效 |
| 窗口字数 | 16 | 一屏显示几个字，拉伸布局下越多越扁 |
| 文字布局 | 拉伸铺满 | 拉伸 / 居中 / 靠左 / 靠右 |

## 权限

- `net.fetch` —— 把当前歌词 POST 给本机的桥接程序（`http://127.0.0.1:8765/state`）

## 已知限制

- 点阵屏一个包最多约 50 字节（16 个汉字），更长的句子靠滑窗显示
- 没有亮度通道，所以做不出“淡入淡出”这类效果
- 只能用于 Windows 上的 Folia + Halo PixelBar（USB 连接）

## 安装

1. 把 `halo-lyric` 目录压成 zip（或直接用发布包），拖进 Folia 的模组面板；
2. 模组面板里点「重载」，启用「Halo PixelBar 歌词」并确认（未签名提示属正常）；
3. 按上面的前置条件装好 HaloBridge；
4. 放一首有歌词的歌。
