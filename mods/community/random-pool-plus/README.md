# 随机池＋（random-pool-plus）

给 Folia 0.7.x 用的歌词动画随机池补丁，版本 1.1.2。

## 它解决什么

Folia 自带的「每首歌随机歌词动画」候选是「全部样式表 ∩ 内建白名单」，通过模组注册的样式不在白名单里，所以勾不上。

本模组不改宿主，只在公开 API 上加一层：

1. `folium.visualizer.listModes()` 取回全部已注册样式（返回项自带 `kind: 'builtin' | 'mod'`）；
2. 勾选任意样式组成自己的池；「全选」存的是「跟随清单」，之后新装的样式自动并入；
3. 监听 `playback.songChanged`，收到事件立即抽签并调 `folium.visualizer.setMode(id)`，不等旧样式播完；
4. 抽签用**洗牌袋**（洗牌轮换）：一整轮里每个样式各出现一次，一轮用完再重洗，且新一轮第一次不与上一轮最后一次相同——同一个样式的**平均间隔接近池里的样式数量**（只装内建时在 17 首上下），不会隔两三首又撞上。因为第 6 条会每 4 抽塞一次模组样式，模组样式的出现会比内建样式更频繁，内建样式的间隔相应拉长；
5. 再挡一道「最近三首不重复」：跨轮交界抽到最近用过的样式时，从袋里换一个没在最近名单里的；
6. 池里同时有内建与模组样式时，每 4 抽强制一次模组样式，否则按纯概率模组样式占比很低。

不针对任何具体样式或具体模组做适配：凡是注册到 Folia 的歌词动画样式，无论内建还是模组提供，都进同一个池、同权参与抽签。

## 安装

1. 整个 `random-pool-plus` 文件夹放进 `%APPDATA%\Folia\mods\`。
2. 重启 Folia（托盘退出，任务管理器确认没有 Folia 进程）。
3. 设置 → 模组 → 「随机池＋」→ 启用。信任对话框只列两项权限：`visualizer.mode`（切换歌词样式）、`filesystem.data`（在模组自己的数据文件里存配置）。本地未签名模组会标「未签名」，不影响加载。
   - 改过模组文件后内容摘要会变，宿主会要求重新确认一次。

## 使用

1. 播放器面板切到「随机池＋」标签：开关、全选 / 仅内建 / 仅模组 / 清空、逐项勾选、重抽一次、重新读取。
2. 面板里列出的项 = 内建样式 + 当前已装的模组样式，数量随安装的模组变化。
3. **把播放页自带的「每首歌随机歌词动画」关掉**，两套随机同时开会互相抢。
4. 命令面板两条：`随机池＋：重抽一次`、`随机池＋：开/关接管`。
5. 新装模组需重启 Folia 才会加载；之后打开面板会自动重读，或点「重新读取」。

## 说明与限制

- 切换样式走公开的 `visualizer.setMode`，等同于手动换样式；不写宿主文件、不改 `app.asar`，Folia 自更新不会冲掉。
- 换歌尽量不卡：每首歌只在 `playback.songChanged` 那一瞬间写一次 `setMode`；`listModes` 的枚举挪到切歌后 1.5 秒做，不占切换那一帧；面板只更新顶部状态行，不重建列表；上一次 `setMode` 还没落地时不会重复写。
- 池为空或只剩一种时保持不动；切向当前正在用的样式会跳过，不重复写入。
- 配置存在模组自己的数据文件里（`folium.storage` 的 `config` 键，`{enabled, ids}`），`ids` 为 `null` 表示跟随全量清单；不写宿主的 `localStorage`。
- 不写任何诊断键、不发起网络请求、不读播放内容；运行信息只走 `folium.log`（宿主日志里以 `[random-pool-plus]` 开头）。
- 只使用 Folium 1.x 现行 API（`visualizer.*` / `events.on` / `registries.*` / `log`），不含宿主已标记为 Folium 2 移除的旧内部接口。
- 两套随机互斥是宿主的设计：本模组切样式时，宿主的「每首歌随机歌词动画」需要你手动关，模组无法代替你去改那个开关。
