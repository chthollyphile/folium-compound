# BPM 歌词样式导演

适配 **Folia 0.7.22 桌面版** 的自定义 Folium 模组。每首歌按 BPM 区间选择一次歌词动画，支持播放器当时已加载的内置与第三方样式。

带完整的可视化设置页：增删/拆分 BPM 区间、下拉选择样式、试算规则、单曲校正、检测选项和缓存管理。无需 AI 接口、密钥或另外安装分析模型。

## API 兼容说明

设置部分已只使用新版 `section.settings` 和 `settings.onChange`，移除了 `section.params` 兼容写法。

**这个版本仍会提示使用 `folium.internals`。** 当前 Folium 1.7 没有切换内置歌词样式、控制内置随机样式开关的公开替代接口。官方将它列为 Folium 2 会删除且没有替代项的能力，所以这部分无法靠改名迁移，也不能承诺兼容 Folium 2。v1.0.0 已采用新版设置接口，但并未消除核心内部接口弃用提示。

若要继续自动选择现有内置和第三方模式，需要 Folia 先提供相应的公开控制接口。只使用目前的公开接口可以另做由本模组自行绘制的歌词动画，但不能因此继续选择 Folia 原有模式，两者功能不同。

## 安装

1. 在 Folia 设置中搜索“模组”，开启“模组系统”。
2. 把 `bpm-style-director-1.0.0.zip` 拖入模组管理面板，安装或更新并启用 **BPM 歌词样式导演**。
3. 确认 Folia 弹出的原生启用窗口。自定义模组显示“未验证”，表示没有官方签名。
4. 按 **Ctrl+K**，搜索 **BPM 导演：打开设置**。也可打开首页的 **BPM 导演** 页签、播放侧栏的 **BPM 导演** 页签，或展开模组自身的设置区。

目前只适配 0.7.22。后续 Folia 版本应重新核对接口，不要自行去掉版本限制强行启用。

## 设置界面

### 正在播放与 BPM

页面顶部显示歌曲、BPM、数据来源、估算置信度及目前执行状态。

- **重新检测**：重新估算当前歌曲。已有手动校正时按钮禁用，先清除校正再重测。
- **立即应用**：按当前 BPM 与已保存规则重新选择样式，也可解除本曲的手动接管。
- **单曲校正 / 保存 BPM**：输入 30–360 之间的 BPM，只记在本模组数据里，不改歌曲标签。
- **清除校正**：恢复使用缓存或自动检测。
- **÷2 / ×2**：快速修正节拍识别中常见的半拍、倍拍歧义，并记住校正结果。

手动校正按歌曲来源与 ID 保存，再次播放同一首歌会直接使用。不同平台的同名歌曲不会共用校正。

### BPM 区间与样式

默认规则如下，可全部改动：

| BPM | 歌词样式 |
|---|---|
| 30 ≤ BPM < 90 | 浮名 |
| 90 ≤ BPM < 120 | 流光 |
| 120 ≤ BPM < 150 | 商籁 |
| 150 ≤ BPM ≤ 360 | 凝彩 |

上限不包含在区间内，最后一行上限写成 361 是为了包含 360。可以拆分、删除和新增区间；区间不能重叠，空缺区间保留当前样式。

样式下拉框读取播放器当前实际加载的模式，第三方动画也可以选。刚启用另一个动画模组后，可重新打开本设置页刷新列表；已经卸载的样式不会被强行套用。

**试算 BPM** 只显示某个数值会匹配哪个区间，不改变播放样式。修改规则或检测选项后点击 **保存设置**，保存时会检查区间冲突，新规则用于当前歌曲和之后的歌曲。

### 自动切换与检测

- **开启按 BPM 自动切换**：总开关。
- **本曲手动切换后暂停自动**：默认开启。你手动选了别的动画或开启随机模式后，本曲由你控制；下一首恢复自动。不会不停抢回样式。
- **没有 BPM 时自动检测**：默认开启。
- **允许额外读取在线播放音频**：默认关闭。关闭时仍能使用该曲已有的 BPM、Folia 缓存、已在内存中的 Blob 音频及手动校正；只有打开后才尝试直接读取在线播放 URL，跨域或来源限制仍可能导致不可读取。
- **停用时恢复之前的样式**：默认开启。正常停用或关闭自动切换时，恢复本模组接管前的模式及随机开关；若你已手动接管，会保留你的选择。
- **估算置信度门槛**：默认 0.45。低于门槛时保留当前样式或使用你设置的兜底样式。该门槛只针对本模组提供数值置信度的估算结果。
- **分析时长**：默认 60 秒，20–120 秒。为解码可能需读取完整音频，节拍计算取其中一段；不会只请求这么多秒的网络数据。
- **分析文件上限**：默认 96 MiB，可改为 16–256 MiB，超过时停止读取并给出提示。
- **未知 / 低置信度时**：默认保留当前样式，也可以指定一个兜底模式。

## BPM 来源与准确性

优先级依次为：手动校正 → 可用的歌曲 BPM / Folia 已有分析缓存 → 本模组记忆 → 本地音频估算。

Folia 没有给既有分析缓存提供统一的数值置信度，因此界面只注明来源，不虚构置信度。自动估算使用音频频谱起音和周期相关性，在独立线程计算；对节拍稳定的音乐更有效，对自由速度、弱鼓点、复杂切分或强副拍歌曲可能存在误差。

**BPM 表示速度，不等同于情绪或“激烈程度”。** 规则由你决定，自动估算不是对所有音乐都准确的鉴定。对不合适的单曲，直接填写 BPM、调整区间或手动选样式即可。

当前估算器搜索约 45–220 BPM，手动校正可写 30–360 BPM。缓存最多记忆 500 首，清理自动检测记忆会保留手动校正。

## 播放与兼容

切歌后先用已有 BPM，第一次没有结果时，需等读取和分析完成才会切换。再次播放可复用结果。快速切歌会取消旧请求，旧曲返回的 BPM 不会套用到新曲。Automix 过渡期间按当前显示的歌曲处理，不把另一声道的音频误记到当前歌曲。

音频必须能被 Folia 的播放/解码环境读取。对需要自动转换的 ALAC 等格式，请开启 Folia 的“自动转换无法播放的音频”；转换完成后可点“重新检测”。本模组只负责 BPM 与样式选择，不修复音频解码器。

与 AI 导演、随机样式切换等其它自动选择器一起使用时，可能互相覆盖；建议一次只用一个自动选择器。内置随机开关会在本模组实际接管样式时临时关闭，停用时按原状态恢复。

## 数据与停用

本模组只保存规则、BPM 与校正数据，不写入音乐文件。Folia 的分析缓存只读；模组自己的数据通过 Folium 存储接口保存。音频计算在本机完成，在线音频是否额外读取由对应开关决定。

在模组面板停用或卸载即可停止自动选择。原音乐文件和 Folia 安装文件没有被修改。

## 适配与验证范围

公开 API 不支持切换内置动画，因此这里使用了当前 Folia 仍提供的 `folium.internals`，调用原版样式设置动作；这也是限定宿主版本的原因。设置面板、命令、生命周期与模组存储使用 Folium 接口。

已验证：

- 28 项公开自动测试，加 1 项本机原版宿主清单校验：规则边界、缺失模式、低置信度、BPM 记忆、单曲校正、快速切歌、手动控制、停用恢复、数据读取上限、静音及已知节奏测试等。
- 12 项隔离 Chrome 交互检查：设置界面、保存、区间冲突、手动校正、切歌、恢复、窄窗口、卸载清理、WebAudio 解码与分析线程、原生 IndexedDB 缓存读取。
- 120 BPM 的合成节拍经过浏览器实际解码和线程检测，返回 120 BPM。这是测试结果，不是对真实歌曲准确率的统计。
- 清单通过本机 Folia 0.7.22 的原版校验器。
- 真实 Folia 0.7.22 的界面截图与当前验证范围见仓库 `docs/VALIDATION.md`。合成节拍测试不代表真实曲库的准确率。
