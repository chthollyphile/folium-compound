# AI 智能 EQ（Folium 模组）

播放歌曲时，把歌名、歌手和**整首歌词**发给云端大模型：它先写一份**歌曲简报**（一句话概括、情绪、风格标签、意象、能量起伏），再给出一条适合这首歌的 10 段均衡器曲线，校验后写进 Folia 的均衡器。

- 适用：Folia 桌面版 **0.7.22+**（Folium **1.7+**）
- 模组 id：`ai-eq`　版本：2.1.0　许可证：MIT
- 模组目录里只有一个 `client.mjs`（单文件构建产物），没有任何相对导入，不执行远程代码

## 功能

- **播放页入口**：播放页**进度条右侧**有一个 AI EQ 小按钮（本模组曲线在位时会高亮），点它打开播放器面板的「AI EQ」标签页：当前 EQ（音效模式、总开关、10 段曲线）、这首歌的曲风/情绪/标签/意象、你的评价状态（可直接点 👍/👎），以及生成 / A/B / 撤销与花费。
- **歌曲简报**：读整首歌词后输出一句话概括、1–4 个情绪词、2–6 个风格标签、2–6 个意象、4–8 段能量起伏（面板里画成小柱状图）。
- **一首歌只问一次**：简报、曲风、曲线、token 花费都按歌曲记住（默认 30 天）。听过的歌直接套用记忆，**不再调用 AI、不再花钱**；换模型/强度/偏好/歌词开关后记忆会自动分开。
- **口味学习**：
  - 面板里的 **👍 / 👎** 会记下这首歌的标签与情绪；
  - 你在「音效」面板里**手动切换音效**也会被记录（例如常切到"低音增强"）；
  - 之后为新歌生成时，提示词里会带上"你喜欢的标签""常手动切到的音效""气质相近歌曲的反馈"，让模型温和参考。可在命令里一键重置。
- **调用与花费**：面板显示本曲与累计的调用次数、输入/输出 token、按你填的单价估算的花费；缓存命中不计调用。
- **曲风可校正**：简报里显示曲风，也可以手动改一条（会随之重新生成），之后请求会带上它。
- **兜底与让位**：失败静默；你改过音效后自动施加暂停；音频效果器窗口打开时曲线暂存、关窗补写；外部 Stage 播放时跳过。
- **A/B 对比 / 撤销**：命令面板和设置面板都有。
- **命令**：生成简报与曲线、A/B 对比、撤销曲线、测试连接、清除歌曲记忆、重置口味学习、重置调用统计。

## 安装

1. Folia：**设置 → 高级 → 模组**，打开「模组系统」（桌面版才有）。
2. 命令面板执行「模组」，把 `ai-eq.zip` 拖进模组面板（或放进 `%APPDATA%\Folia\mods`）。
3. 启用「AI 智能 EQ」，在原生确认窗口确认权限。
4. 展开模组 → 选服务商、保存 API 密钥（模型可留空用预设）。

## 配置

| 设置项 | 说明 |
| --- | --- |
| 服务商 / 接口地址 / 模型 | 预设含 DeepSeek、OpenAI、Kimi、GLM、通义、豆包、Ollama、自定义；地址留空用预设，只允许 HTTPS（本机除外），自动补 `/chat/completions` |
| API 密钥 | 系统凭据库加密保存（Windows 走 DPAPI），不进日志/设置值/视觉配置导出 |
| JSON 输出 | 默认开 `response_format=json_object`，不支持的服务商自动回退一次 |
| 调整强度 | 温和 ±3 / 标准 ±6 / 明显 ±9 dB（宿主上限 ±12，相邻段再限 ≤3 dB） |
| 我的听感偏好 | 一句话，例如「耳机偏低频，希望人声靠前」 |
| **发送整首歌词** | 默认开。最多 6000 字；关闭后只用歌名/歌手/专辑，简报会粗糙、也请求更便宜 |
| **输入 / 输出价格** | 用于估算花费（元 / 百万 tokens），按你的服务商价目填 |
| 换歌时自动施加 | 关掉后只在你点「生成」时请求 |
| 记忆有效期 | 7 / 30 / 90 天 / 长期；期内听过的歌直接套用 |

## 工作原理

```
换歌 ──▶ 歌名/歌手/专辑 + 整首歌词 + 历史口味（喜欢的标签、常切音效、相似歌反馈）
              │
              ▼  一次 chat/completions（JSON）
        genre / summary / emotion / tags / imagery / energy
        reason / curve[10] / confidence / usage(prompt+completion tokens)
              │
       校验（段数、限幅、限斜率、置信度）──▶ applyCurve
              │
       记住：简报+曲风+曲线+花费（按歌曲）──▶ 下次直接套用，不再调用 AI
              │
       👍/👎、手动切换音效 ──▶ 口味记录 ──▶ 影响之后「气质相近」歌曲的提示词
```

模型被要求先读完整首歌再写简报；提示词里包含宿主真实的频段表（`equalizer.getState().bands`），段数变化也能兼容。

## 隐私与数据

- 发送给 AI 服务商的：歌名、歌手、专辑、**整首歌词（≤6000 字，可在设置里关闭）**、你填的听感偏好、历史口味摘要（标签与模式名，不含歌名/账号）。
- **不发送**：音频、账号、Cookie、设备信息、听歌历史列表。
- 不会下载或执行远程内容；模型输出只当数字/文本解析，失败即丢弃。
- 非 HTTPS（本机地址除外）在发送密钥前就会被拒绝。
- 本机保存：歌曲记忆（简报/曲线）、口味（评价/切换记录）、调用统计（次数/token/花费）、曲风。可用命令分别清除。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示「请先在设置里保存 API 密钥」 | 展开设置，粘贴密钥后点「保存」；本机 Ollama 可留空 |
| 401 / 403 / 404 / 429 | 密钥、模型名、地址或额度问题；点面板里的「当前接口」核对地址 |
| 413 请求太大 | 关闭「发送整首歌词」，或换上下文更大的模型 |
| 花费显示 ¥0 | 服务商没返回 usage，或「输入/输出价格」填了 0；按价目填上即可 |
| 同一首歌又请求了 AI | 改过模型/强度/偏好/歌词开关（记忆按这些参数分开），或过了记忆有效期，或点了「生成」（强制重新生成） |
| 换了音效后 AI 不再自动调 | 这是设计：自动施加已暂停，重新打开设置里的「换歌时自动施加」 |
| 简报是"推断"字样 | 那首歌没拿到歌词，模型只能按歌名/歌手/专辑判断 |
| 想重新学口味 | 命令面板执行「AI EQ：重置口味学习」 |
| 想重置花费统计 | 命令面板执行「AI EQ：重置调用统计」 |
| 进度条右侧没有 AI EQ 按钮 | 确认模组已启用；按钮在进度条右侧（折叠胶囊和 Lattice 里也会显示）。也可以直接用命令面板的「AI EQ」命令 |
| 报 `does not provide an export named …` | 旧版本把模组拆成多个文件，宿主只给入口加 `?v=` 指纹、相对导入会被浏览器按 URL 缓存旧模块。2.0.1 起已合并为单文件；升级后**完全退出 Folia 再打开**一次即可 |

## 开发与测试

```bash
# 源码在 _src/（不在模组目录里）
_src/eq.mjs        # 纯逻辑：供应商预设、端点校验、提示词、JSON 解析、曲线归一化
_src/client.mjs    # 宿主交互：面板、命令、事件、记忆、口味、统计、施加

# 改完源码后重新打包成单文件 ai-eq/client.mjs
node _tools/build-mod.mjs

# 测试（Node 24，无需 Folia）
node --test
```

**为什么是单文件**：Folium 只给 client 入口的 URL 加 `?v=<内容指纹>`，入口里的相对导入（`./eq.mjs`）解析出的 URL 不带指纹，会被浏览器的模块表按 URL 缓存。App 不重启、只「重载」模组时，新版 client 可能配到旧版模块，报 `does not provide an export named …`。打包成一个文件后没有任何相对导入，从根上避免这个问题。

测试用 `_tests/mock-host.mjs` 模拟宿主；50 个用例覆盖：记忆命中不请求、简报与 usage 落盘、花费计算、统计累计、口味（👍/手动切换）进提示词、整首歌词发送与关闭、401/400/temperature 回退、超长/低置信度/全 0 曲线、限幅平滑、用户让位、panel-open 补写、A/B、快速切歌防串歌、外部 Stage、进度条按钮与播放页 AI EQ 面板、面板渲染与交互等。

## 已知限制

- 大模型**听不到声音**：简报和曲线是根据文字推断的，不是声学测量；同一首歌换模型结果会不同。
- 歌词可能来自平台、可能不完整；没有歌词时简报质量会下降。
- 只有 10 段 / ±12 dB 的宿主均衡器，模组侧再限制到设定强度与 ≤3 dB/段斜率。
- token 与花费是估算值（按你填的单价、以服务商返回的 usage 为准），不含服务商缓存折扣等差异。
