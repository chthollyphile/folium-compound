# 上架材料说明（先行测试渠道）

> 本文件是提交到 [folium-compound](https://folium-compound.cielaniska.top) 模组市场「先行测试」渠道时用的说明材料与自查清单。
> 最后更新：2026-11-10，对应 `mod.json` 版本 **1.8.0**。

## 一、模组简介

**中文（42 字）**

> 桌面歌词与悬浮窗歌词双形态，多行滚动、鼠标穿透、自由缩放，支持播放器控制与状态记忆。

**English (one sentence)**

> Desktop and floating lyric windows: multi-line scrolling, click-through, free resizing, player controls and remembered layout.

## 二、核心功能

- **两种歌词窗口，一个按钮切换**：桌面歌词窗口（贴边单行/双语，可锁定位置）与悬浮窗歌词窗口（独立大窗口），通过窗口上的切换键或命令面板互相切换。
- **多行歌词滚动**：悬浮窗按可用高度显示 1–N 行完整歌词（当前句高亮、上下句半透明）；高度够时整块居中，不够时按「完整行」整页平移，永不出现半截行或来回抖动。
- **长句横向滚动**：桌面歌词与悬浮窗都支持超长句自动横向滚动（速度按剩余可唱时间与溢出量反推，暂停时停住）。
- **桌面模式（鼠标穿透）**：悬浮窗可整窗隐藏控件并让鼠标穿透，光标移回窗口任意位置时退出键自动点亮，点一下即可恢复操作；也可用命令面板 / 全局快捷键退出。
- **播放器控制**：上一曲、播放/暂停、下一曲、循环模式（关/单曲/列表）、音量、排版三态（原文 / 原文+译文 / 原文+罗马音）、播放列表（悬浮窗内自绘面板，可直接点歌）。
- **进度条快捷按钮**：播放器进度条右侧的「词」按钮一键显示/隐藏歌词窗口，并高亮当前状态。
- **状态持久化**：窗口位置、尺寸、是否固定、桌面模式、排版、上次使用的形态都会记住，重启后原样恢复；字号、颜色等偏好存在模组设置里。
- **外观自定义**：字号（桌面 20–50 / 悬浮窗 20–40）、桌面歌词颜色、悬浮窗当前句颜色、字体来源（系统 / 跟随主题）、底色与不透明度、圆角、描边、底衬、暂停变淡。
- **稳健性**：窗口崩溃自动恢复（每分钟最多 2 次）、任务栏压盖时自动置顶、可选「全屏窗口下保持置顶」、插曲行按空隙处理（不会把 `......` 当成歌词显示）。

## 三、先行测试渠道声明

## 四、已知限制

1. **平台**：目前只在 Windows 上开发和验证。任务栏守卫、`SetWindowPos` 置顶、DWM 圆角处理都是 Windows 专属行为，其它平台未测试。
2. **独占全屏（真全屏游戏）下无法覆盖**：需要检测「其它应用是否全屏」的原生能力，本模组没有权限；无边框全屏窗口已尽力改善（每秒重申置顶 + 重绘一帧，可在设置里关掉）。
3. **歌词本身来自宿主解析结果**：本模组不做翻译、不做罗马音生成，也不做逐字歌词（该功能已按需求移除）。歌词源里没有译文/罗马音时，对应排版态会回退成原文。
4. **需要歌词源支持**：本地 `.lrc`、内嵌歌词、在线歌词都可用；但没有歌词的歌只能显示「此歌曲暂无歌词」。
5. **桌面歌词窗口不可自由缩放**：它的高度跟随字号自动计算（这是 1.3.0 以来的设计）；需要自由缩放的场景请用悬浮窗歌词。
6. **播放列表面板显示的是宿主队列**：外部播放（非宿主队列）时面板会提示无队列；点歌后高亮由宿主回填，可能有约半秒延迟。
7. **权限只有 `playback.read` / `playback.control`**：不读写宿主配置文件，不联网，不执行下载；状态存于 `userData/lyric-float-state.json`（旧文件 `my-lyric-widget-state.json` 会迁移一次）。
8. **未签名时显示「未验证」**：签名由 folium-compound 的 CI 用先行测试（beta）渠道密钥完成，签名覆盖所有文件（含 `mod.json` 与 `preview.png`），**签名后不要再改任何文件**。

## 五、安装与启用

1. 从模组市场下载 zip（或在开发版里把 `mods/lyric-float` 目录放进去）；
2. 打开 Folia → 设置 → 高级 → 模组 → 安装并启用「歌词浮岛」；
3. 首次启用后 **桌面歌词窗口**会直接出现（贴边、半透明、置顶）；
4. 布局微调：设置 → 高级 → 模组 → 悬浮窗歌词。

## 九、版本号约定（重要）

宿主清单校验器 `electron/modSystem/manifest.cjs:87-93` 只接受 **`主.次.修订`（三段纯数字）**：

```
mod.version must be a semantic version like 1.2.3
```

因此 `1.8.0-beta.1` 这类预发布号**无法通过宿主校验**（已实测：`npm run folium:check -- lyric-float` 直接报这条错误）。
「先行测试渠道」的身份由 folium-compound 侧的渠道元数据 + beta 签名密钥表达，而不是写在 `mod.json` 的 `version` 里。
当前提交版本为 **1.8.0**。

## 十、提交（开 issue，不需要 fork）

官方流程见 [Folium 模组开发与贡献指南](https://github.com/chthollyphile/folia-major/blob/main/docs/folium/contributing.md) 第 6 节：**不需要 fork**，只要源码仓库公开、mod.json 通过校验、为发布版本打 tag，然后在 folium-compound 仓库开一个「模组提交」issue 即可。

1. **模组目录**：本仓库根目录就是模组目录（`mod.json`、`client.mjs`、`main.cjs`、`preview.png`、`LICENSE`）。CI 只排除以 `.` 开头的文件和 `node_modules`，其它会原样收录（含 `docs/`，体积远小于 16 MB 上限）。提交前跑一次：
   ```bash
   cd D:\folia-dev\folia-major
   npm run folium:check -- lyric-float
   ```
   期望输出 `no problem found.`（只剩「not signed」note，签名由 CI 做）。
2. **`mod.json` 字段**（已满足）：`folium: 1`、`id`、`name`、`version`、`description`、`client`、`main`、`preview`、`permissions: ["playback.read","playback.control"]`。
3. **`preview.png`**：1280×720、< 1 MB、相对路径写在 `mod.json.preview`。
4. **本文件 `docs/SUBMIT_GUIDE.md`**（简介 / 功能 / 先行测试声明 / 已知限制）。
5. **权限说明**：为什么需要 `playback.read` 与 `playback.control`（读播放状态与歌词、发播放控制指令）；不申请 `filesystem.data`，因此不使用 `folium.storage`。
6. **变更说明**：相对上一个公开版本的改动摘要（1.7.x 系列：新增悬浮窗歌词形态、播放列表面板、桌面模式退出键、全屏置顶刷新、桌面歌词颜色）。
7. **作者信息与联系方式**（GitHub `GUDUYUNI99` / 邮箱），以及 issue 里说明「目标渠道：preview（先行测试）」。

issue 需要填：模组 id、源码仓库、版本（tag 优先，也可写分支或完整 commit）、模组目录、模组说明、逐条权限说明、许可证（MIT）。CI 会把版本解析成具体 commit、只取回该提交做格式与收录规则检查，并在 issue 里回复「格式检查通过，请等待维护者审查」或指出要改的地方。
8. **签名**：不要自己签；由 folium-compound 的 CI 使用 beta 渠道密钥签名。签名后任何文件改动都会让签名失效，需重新签。
